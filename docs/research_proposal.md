
# Research Proposal

## Research Title
Automated Concrete Crack Detection Using Computer Vision Techniques for Structural Health Monitoring

## Introduction
Concrete structures may develop surface cracks due to environmental conditions, loading, shrinkage, and material deterioration. Detecting visible cracks is an important part of structural inspection.

Computer vision techniques can process digital images to identify potential cracks and support inspection activities.

## Problem Statement
Manual inspection of concrete surfaces can be time-consuming and inconsistent. Automated computer vision methods may improve the efficiency of visible crack detection.

## Research Objectives
1. Develop a concrete crack detection prototype using Python and OpenCV.
2. Implement selected image-processing techniques.
3. Compare their detection performance.
4. Evaluate results using appropriate metrics.
5. Identify limitations and future improvements.

## Research Questions
RQ1: How effectively can traditional computer vision techniques detect visible concrete cracks?

RQ2: How does image preprocessing influence detection performance?

RQ3: Which selected method performs best on the evaluation dataset?

## Proposed Methodology
1. Select and inspect a labeled concrete crack dataset.
2. Apply preprocessing techniques.
3. Implement crack detection algorithms.
4. Evaluate methods on held-out test images.
5. Compare experimental results.
6. Document findings and limitations.

## Research Status
